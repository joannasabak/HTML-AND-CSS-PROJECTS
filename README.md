# HTML-AND-CSS-PROJECTS
 
A collection of study projects built with HTML and CSS to practice and showcase front-end fundamentals.
 
## 🚀 Projects

| Project | Focus |
|---|---|
| `Basic_HTML_and_CSS` | Core markup and styling basics |
| `Basic_HTML_and_JavaScript_1` | Adding simple JS interactivity |
| `Creating-CSS-Effects` | CSS effects and styling techniques |
| `One-Page-Website` | Single-page site layout |
| `Simple-Recipes` | Small content/layout exercise |
| `The-Pet-Shop-Website` | Multi-section site build |
| `Academy-Cinemas` | Exercise with bootstrap |
| `Assignment.html`, `Astronaut.html`, `Cat_party.html`, `Fun_fact.html` | Standalone practice pages |
| `Images` | Shared image assets |

## 🛠️ Built with

- HTML5
- CSS3
- JavaScript (in a few projects)
